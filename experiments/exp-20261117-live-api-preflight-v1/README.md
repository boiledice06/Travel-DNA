# 실험 exp-20261117-live-api-preflight-v1

- 실행 일시: 2026-11-17 16:43 KST (`http-results.json`의 UTC 시각 참조). Git 기준 리비전 `98acc4abc0349fe62af4cd0a94e28f77f9285d56`.
- 목적: 외부 인증이 없는 상태에서 실제 FastAPI와 두 합성 프로필의 인증 이전 단계 및 실패 경계를 확인한다. 가설: 프로필과 Likert는 외부 호출 없이 성공하고 Vertex 또는 장소 검색은 인증이 필요하다.
- 방법: `run_preflight.py`는 실제 `app.main:app`을 Uvicorn으로 구동하고, 개인정보 보호를 위해 서버 저장소만 이 실험 폴더로 변경한다. 외부 AI 또는 장소 제공자는 모의 주입하지 않는다. A는 조용한 독립서점·전시와 혼잡 기피, B는 활동·유명 관광지 선호의 합성 입력이다. 문항 순서 및 값은 스크립트에 기록되어 있다. 데이터셋 및 난수 시드 없음. 원본 응답 상세·키는 결과 로그에 저장하지 않는다.
- 재현: Python 3.14.0, FastAPI 0.162.2, Uvicorn 0.54.0, Pydantic 2.14.3, google-genai 3.0.0. backend 의존성은 `backend/travel-preference-mvp/uv.lock`을 참조한다. 같은 결과 파일 덮어쓰기는 금지되므로 스크립트와 별도 빈 실험 폴더를 만들어 실행한다. 기존 실험 저장소는 보존한다.
- 관찰: `http-results.json`: `/docs`, 프로필, 설문 시작·제출은 200. A/B Vertex 대화 및 장소 추천은 인증 오류로 502, 키 없는 별도 Places 검색은 503. 대화 실패 후 서버 계약만 검사하기 위해 설문에서 제약·확정을 직접 진행했으며 각각 200이다. 이 확정은 실제 AI 대화를 통한 취향 확정이 아니다.
- 시간: 개별 요청 시간은 `http-results.json`에 있다. 약 12–13초의 502는 인증 실패 시간으로 성공 응답 시간이나 추천 성능이 아니다. 표본은 각 사용자 1회이며 분포 추정에 부적절하다.
- 해석과 한계: 자격증명 및 원격 서비스가 준비되면 성공할 것이라는 가설은 검증하지 못했다. 실제 Vertex 답변, 실제 장소, 장소 출처·중복·서울 경계, A/B 개인화와 일정 품질은 미검증이다. 모의 단위 테스트의 결과를 실제 응답으로 취급하지 않는다.
- 코드 후속 변경: 모든 장소 제공자 요청이 실패해도 빈 성공 응답으로 보이던 문제를 별도 회귀 테스트 후 수정했다. 이 변경은 본 HTTP 실험 이후이므로 본 측정값은 변경 전 코드의 결과다.
