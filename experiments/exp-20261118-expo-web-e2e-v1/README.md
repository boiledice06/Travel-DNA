# exp-20261118-expo-web-e2e-v1

목적: 실제 Expo Web에서 서울 2박 3일 취향 대화 및 외부 장소 결과의 모바일 렌더링 검증. 가설: 실제 API 결과가 지도와 3일 일정에 표시되고 모든 모바일 컨트롤이 겹치지 않는다.

실행일 2026-11-18 (Asia/Seoul); revision `ca3b39c`와 기존 미커밋 작업 트리. 데이터는 테스트 사용자의 조용한 박물관·미술관·산책 선호, Gemini 대화, 새 Kakao/TourAPI 검색 결과. 랜덤 시드는 설정하지 않았으며 외부 API 응답과 모델은 시점에 따라 변한다. Expo/Node 의존성은 프로젝트 lockfile, Python 의존성은 backend `uv.lock` 참조.

관찰: 15개 실제 서버 추천이 세 날짜에 각 5개로 표시되고 선택·상세가 작동했다. 390px 폭에서 긴 마커 라벨이 지도 버튼과 겹쳤다. AI 대화 스크린샷과 시작부터 연속 흐름은 확보하지 못했다. 통계적 추론은 수행하지 않았다. 전체 방법, 명령, 제한, 파일별 증거는 `../../verification/E2E_VERIFICATION_REPORT.md`, 이미지들은 `../../verification/e2e-screenshots/` 참조. 이전 저장 응답은 주입하지 않았다. 원격 보관 상태는 별도로 확인해야 한다.
