# Travel DNA 최종 발표 패키지

실험 `exp-20261125-golden-path`의 Expo Web 캡처와 발표 운영 파일입니다. 서울 2박 3일의 실제 추천 기록 두 건을 사용합니다. A는 활기찬 체험형, B는 기존 조용한 휴식형입니다.

```powershell
npm run demo
# 다른 PowerShell 창
npm run demo:reset
```
