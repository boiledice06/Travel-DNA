# 서울 2박 3일 발표 대본

`npm run demo`를 실행한 뒤 [시나리오 선택](http://127.0.0.1:8785/demo)에서 **A. 활기찬 체험형** 또는 **B. 조용한 휴식형**을 선택합니다. 새 시연을 시작하려면 `npm run demo:reset`을 실행하고 선택 화면을 다시 엽니다. 두 유형 모두 서울 2박 3일, 2명, 친구, 도보·지하철, 보통 예산, 오전입니다. 선택한 유형에 아래 문장을 그대로 입력합니다.

## A. 활기찬 체험형

- 여행 목적 — `지역 먹거리를 즐기고 시장을 둘러보며 활동적인 체험을 하고 싶어요.`
- 설문 1~5번 — **5, 5, 5, 5, 4**
- 대화 답변 1 — `지역 시장에서 먹거리를 맛보고 활기찬 체험을 하고 싶어요.`
- 대화 답변 2 — `전통시장과 길거리 음식을 즐기고 직접 참여하는 활동을 좋아해요.`
- 대화 답변 3 — `사람들이 북적이는 시장에서 로컬 음식을 먹고 싶어요.`
- 꼭 원하는 것 — `전통시장, 지역 먹거리, 활동적인 체험`
- 피하고 싶은 것 — `술집`

설문 제출 직후에는 로컬·골목에서 선호하는 분위기를 묻습니다. 두 번의 후속 질문에 순서대로 답하면 필수·제외 조건 화면이 열립니다. **조건 제출 → 취향 확정 → 서울 장소 추천 받기**를 누릅니다. 확정 키워드는 **전통시장 · 길거리 음식 · 로컬 체험 · 북적이는**입니다. 실제 검색 기록에는 전통시장·향토음식점·길거리 음식·로컬 체험 등이 있으며, 이자카야도 검색어에 포함됐습니다. 전체 추천의 상위 세 후보는 **남대문시장 · 광장시장 · 경동시장**입니다.

**Day 1 → Day 2 → Day 3**을 눌러 일정을 확인합니다. Day 3 패널을 펼쳐 동작구름카페나 국립중앙박물관 전통염료식물원 상세에서 사진을 보고 찜합니다. **찜한 장소 → 내 여행 → 취향 DNA**에서 저장과 확정 취향을 확인합니다.

## B. 조용한 휴식형

아래 조작은 Edge에서 발표 서버를 열고 `npm run demo:reset`을 실행한 상태를 전제로 합니다. 발표자는 직접 조작합니다. 시간은 설명을 포함한 약 2분 30초의 진행 예시입니다.

| 경과 | 조작 | 확인할 화면 |
| --- | --- | --- |
| 0:00 | 서울 야경을 보여 주고 **서울 여행 시작하기**를 누릅니다. | 인트로에 **발표 모드 · 실제 추천 기록 재생**이 보입니다. |
| 0:12 | 지도에서 **여행 설계**를 누릅니다. 2명, 친구, 도보·지하철, 보통, 오전을 확인합니다. 여행 목적을 입력하고 **취향 설문 시작**을 누릅니다. | 서울 2박 3일 여행 조건, 예산 메모는 비워 둡니다. |
| 0:33 | 문항 순서대로 **4, 2, 2, 3, 3**을 고르고 **설문 제출**을 누릅니다. | 다섯 번째 응답 이후 제출할 수 있습니다. |
| 0:49 | AI의 안내를 읽고 아래 답변 한 문장을 입력해 **답변 보내기**를 누릅니다. | 실제 응답으로 필수·제외 조건 화면이 열립니다. |
| 1:04 | **꼭 원하는 것**에 `박물관, 미술관`, **피하고 싶은 것**에 `술집`을 넣고 **조건 제출**을 누릅니다. 초안을 확인한 뒤 **취향 확정**을 누릅니다. | 확정 키워드 **회화전시 · 조용한 · 실내예술**과 필수·제외 조건이 보입니다. |
| 1:23 | **서울 장소 추천 받기**를 누릅니다. DNA 모션 후 지도에서 **전체**를 누릅니다. | 번호 마커와 연결선, 하단 패널이 순서대로 나타납니다. |
| 1:41 | **Day 1 → Day 2 → Day 3**을 차례로 누릅니다. | 각 날짜에 방문 순서가 지정된 장소 5곳을 볼 수 있습니다. |
| 1:54 | Day 3의 하단 손잡이를 위로 150px 정도 끌어 확장합니다. 두 번째 장소 **[K드라마 촬영지] 공근혜갤러리**까지 목록을 스크롤하고 사진 카드를 누릅니다. | 상세에 관광공사 사진, 원본 출처와 KOGL-1이 나타납니다. |
| 2:12 | 상세에서 저장 버튼을 누릅니다. 뒤로 간 뒤 **찜한 장소**에 저장된 갤러리를 확인합니다. | 상세의 북마크가 채워지고 찜 목록에 1곳이 나타납니다. |
| 2:22 | **내 여행**으로 전환해 Day 3까지 스크롤합니다. 필요하면 끝에 **취향 DNA**를 열어 확정 키워드를 짚습니다. | 3일 각각 5곳, 날짜와 방문 순서, 검증된 사진이 보입니다. |

### 그대로 입력할 문장

- 여행 목적: `조용한 박물관과 미술 전시를 관람하고 여유롭게 산책하고 싶어요.`
- 설문 직후 앱 안내: “설문 반영했어요. 구체적으로 좋아하는 장소·분위기·키워드가 있으면 알려 주세요.”
- 대화 답변: `조용한 회화 전시에 관심이 있어요.`
- 답변 직후의 실제 응답: “이제 필수적으로 필요한 것(꼭 원하는 것)과 피해야 하는 것을 적어 주세요. 없으면 ‘없음’이라고 적어 주셔도 됩니다.”
- 꼭 원하는 것: `박물관, 미술관`
- 피하고 싶은 것: `술집`

### 고정 방문 순서

| 날짜  | 방문 순서                                                                                                                                    |
| ----- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| Day 1 | 김세중미술관 → 국립중앙박물관 → 국립중앙박물관 전통염료식물원 → 리움미술관 → 서울시립미술관 서소문본관                                       |
| Day 2 | 한강시민공원 뚝섬수영장(실외) → 국립현대미술관 덕수궁 → 서울역사박물관 → 환기미술관 → 퐁피두센터 한화                                        |
| Day 3 | [북악하늘길 2산책로] 하늘교~성북천발원지 → [K드라마 촬영지] 공근혜갤러리 → 국립현대미술관 서울 → 대한민국역사박물관 → KCDF 갤러리숍 공예정원 |
