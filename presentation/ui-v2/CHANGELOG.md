# Travel DNA UI V2 변경 내역

기준 리비전 `a3d604d` · 작업 브랜치 `codex/presentation-ui-v2`

| 화면          | 변경 사항                                                                                                                                           |
| ------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 인트로·온보딩 | 서울 야경을 화면 전체에 배치하고 시작·데모 동작을 하단에 모았습니다. 사진의 느린 이동, 브랜드와 문구의 순차 표시를 적용했습니다.                    |
| 여행 조건     | 서울 2박 3일 범위와 인원·동행·교통·예산·활동 시간 그룹을 구분했습니다. 주 동작을 고정하고 조건을 보내는 시점을 안내합니다.                          |
| 취향 설문     | 서버에서 받은 문항과 척도를 사용합니다. 응답 수, 진행 바, 문항별 척도와 선택 피드백을 적용했습니다.                                                 |
| 취향 대화     | 메시지, 입력란, 빠른 응답, 답변 준비를 각각 배치했습니다. 요청 실패 때 입력을 유지하고 같은 답변을 다시 보낼 수 있습니다.                           |
| Travel DNA    | 인터랙티브 점·선 그래픽과 서버 키워드, 필수·제외 조건을 표시합니다. 로컬 여행 기록은 별도의 스펙트럼과 해석으로 보여 줍니다.                        |
| 서버 추천     | 검색 요청 동안 브랜드 화면을 표시하고, 응답을 받으면 Day 1을 지도에 표시합니다. 마커 그룹, 순서선, 패널의 등장에 짧은 시차를 두었습니다.            |
| 지도          | 여행 설계 바로가기, 검색, 옵션과 지도 도구를 정리했습니다. 날짜 범위에 맞춰 카메라를 조정하며, 화면 안에 있는 마커를 선택할 때 카메라를 유지합니다. |
| 추천 패널     | Collapsed·Compact·Expanded 높이를 실제 드래그 도중 반영합니다. 위치와 속도로 스냅하며 손잡이 탭과 목록 버튼을 함께 제공합니다.                      |
| 카드·상세·찜  | 사진과 장소 정보의 계층을 통일하고, 썸네일과 본문형 카드의 크롭을 정리했습니다. 저장 피드백과 사진이 없을 때의 표현을 추가했습니다.                 |
| 내 여행·탭    | Day 1–3 방문 순서를 타임라인으로 배치하고 일정의 장소에서 상세로 진입할 수 있습니다. 각 탭의 아이콘 활성 상태를 구분했습니다.                       |

시각적 수정은 `VERIFICATION.md`의 반복 검토와 연결됩니다. 백엔드 API와 추천·영속화 로직은 기존 경로를 사용합니다.
