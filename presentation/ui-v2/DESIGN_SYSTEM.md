# Travel DNA 디자인 시스템

## 색상과 타이포그래피

공통 값은 `src/theme/index.ts`에서 관리합니다. 모든 앱 화면은 React Native StyleSheet를 사용합니다.

| 역할      | 색상                  | 적용                                  |
| --------- | --------------------- | ------------------------------------- |
| 본문      | `#132D36`             | 제목, 장소명, 조건, 응답              |
| 주 동작   | `#123943`             | 기본 버튼, 선택한 날짜와 지도 핀      |
| 강조      | `#077D76`             | 취향, 진행률, 선택 경계               |
| 밝은 강조 | `#83D8C5`             | 사진 위 시작 버튼, 어두운 표면 위 DNA |
| 배경      | `#F7F7F1` · `#FFFFFC` | 페이지, 도구와 패널                   |
| 보조      | `#4E6469` · `#DCE4DD` | 설명, 경계와 차트 트랙                |
| 제외·오류 | `#A04D3C` · `#9D443A` | 제외 조건, 요청 오류                  |

디스플레이 38, 제목 30, 소제목 20, 본문 15, 보조 12를 기준으로 시스템 글꼴을 사용합니다. 인트로 제목 행간 49, 폼 본문 행간 24입니다. 긴 지도 이름은 선택 라벨 안에서 줄임표를 쓰고 상세에서 전체 이름을 보여 줍니다. 탭과 버튼의 일반 터치 영역은 최소 44dp입니다.

간격 4·8·12·20·28·40, 모서리 10·16·24를 기준으로 사용합니다. 문서형 화면은 구분선과 여백으로 절을 나눕니다. 그림자는 지도 위 도구, 패널과 같이 레이어 분리가 필요한 요소에 적용합니다. 차트 값과 날짜나 순번은 문자로도 전달합니다.

## 모션

| 동작        | 기준                        | 구현                                                         |
| ----------- | --------------------------- | ------------------------------------------------------------ |
| 선택 피드백 | 약 145ms와 짧은 spring      | 설문·조건 선택과 북마크                                      |
| 요소 등장   | 240ms ease-out              | 인트로 문구, 새 메시지, 키워드, 상세                         |
| 화면 전환   | 320ms 기준                  | 스택 페이드. 여행 모달은 플랫폼 기본 페이드                  |
| 지도 카메라 | 380ms 기준                  | 가까운 이동 보간 또는 네이티브 카메라 API                    |
| 추천 패널   | 감쇠 30, 강성 290, 질량 0.9 | 드래그 중 높이 직접 반영, 종료 속도를 반영한 spring          |
| DNA 그래픽  | 대기 중 2.4초 주기          | Reanimated 점·연결선. 결과 화면에서는 짧게 자리 잡은 후 정지 |

인트로의 사진 이동은 1회 실행합니다. 취향 키워드와 마커의 순차 등장은 짧은 최대 지연을 두어 긴 목록에서도 화면 사용을 늦추지 않습니다. 추천 대기 모션은 실제 요청 동안만 실행되며, 응답이 도착하면 지도 마커, 방문 순서선, 추천 패널을 이어서 보여 줍니다. 기기의 Reduce Motion 설정을 읽어 진입, 카메라, spring과 반복을 줄입니다.

## 데이터 표현

서울 야경과 관광공사 사진의 기존 출처를 표시합니다. 사진이 비어 있거나 요청이 실패하면 카테고리 아이콘과 지도 등고선 패턴을 표시합니다. 서버에서 확정한 키워드와 조건은 여행 기록을 기반으로 계산한 취향 스펙트럼과 서로 다른 제목으로 표시합니다. 기존 서버에 없는 일치도는 렌더링하지 않습니다. 지도 연결선은 방문 순서의 직선 연결이며 화면에 실제 이동 경로에 관한 고지를 유지합니다.
