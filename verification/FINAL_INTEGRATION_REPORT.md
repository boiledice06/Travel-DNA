## 수정과 관찰된 제한

1. TourAPI ID의 URL 이중 디코딩으로 상세 화면이 장소를 찾지 못하던 문제를 수정했다. 기존 ID를 우선 찾고 필요할 때만 디코딩된 ID로 찾으며 저장도 실제 ID를 사용한다. 세 TourAPI 상세와 찜 목록 상세 이동을 확인했다.
2. 저장된 장소가 서버 추천 앞에 삽입되면서 날짜 배정이 바뀌는 문제를 수정했다. 서버 추천의 기존 순서를 우선하고 저장 전후 15곳의 날짜 번호가 복원됨을 확인했다.
3. 웹에서 선택된 긴 마커가 오른쪽 지도 버튼과 겹쳐 마커의 수평 위치를 조정했다. Day 2 서울식물원 호수공원에서 겹침이 해소됨을 확인했다. 화면 가장자리의 다른 마커와 네이티브 지도는 별도 검증이 필요하다.
4. 필터를 바꾸면 필터 결과를 다시 3일로 배치하므로 날짜가 바뀐다. 이것이 사용자가 기대하는 일정 필터 동작인지 별도 제품 판단이 필요하다.

## 재현 및 보관

백엔드 디렉터리에서 `CORS_ALLOW_ORIGINS=http://localhost:8084,http://127.0.0.1:8084`를 설정하고 `.venv/Scripts/python -m uvicorn app.main:app --host 127.0.0.1 --port 8767` 실행. 프로젝트 루트에서 `EXPO_PUBLIC_RECOMMENDATION_SERVER_URL=http://127.0.0.1:8767`, `EXPO_OFFLINE=1` 설정 후 `npm run web -- --port 8084`. 실제 API 키와 외부 네트워크가 필요하다. 결과는 장소 데이터 및 공급자 상태에 따라 달라진다.
