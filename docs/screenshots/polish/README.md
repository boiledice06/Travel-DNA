# Travel DNA UI 개선 화면 검증

- 검증일: 2026-11-17 (Asia/Seoul). 기준 코드: `5b51abb` 이후 UI 변경.
- 목적: 기존 `docs/screenshots/verification/`의 390×844 모바일 웹 검증 결과와 비교해 인트로, 취향 분석, 지도 패널, 상세의 가독성과 조작을 확인한다.
- 환경: Windows, Expo Web 인앱 브라우저 뷰포트 390×844. 저장된 JPEG는 390×843이다. 제공된 테스트용 FastAPI와 모의 AI·장소 후보를 사용했으며 실제 외부 서비스 응답이 아니다. 무작위 시드는 사용하지 않았다.
- 방법: Intro → 데모 지도 → 조건 입력 → 설문 → 서버 선택지 → 취향 확정 → 추천 지도 → 패널 상태 및 Day 선택 → 상세 복귀를 실제로 조작했다. 파일은 실행 화면의 브라우저 캡처다.

## 관찰

- `01-intro.jpg`: 서울 야경과 어절 단위 줄바꿈, 저작자 정보, CTA를 확인했다. 이미지 사용 조건은 `assets/README.md`에 기록했다.
- `02-conditions.jpg`, `03-likert.jpg`, `04-chat.jpg`: 조건 입력, 서버 문항·척도와 2/5 진행률, 선택 강조 및 대화 입력을 확인했다. 조건 아래에서 설문을 시작해도 설문 상단이 보였다. 모의 서버는 첫 답변 후 조건 단계로 넘어가므로 다중 대화의 사용자 버블, 자동 스크롤, 실제 휴대폰 키보드는 검증하지 못했다.
- `05-map-collapsed.jpg`, `06-map-compact.jpg`, `07-map-expanded.jpg`: 접힌 화면에서 상단 검색·필터가 숨겨지고 날짜 선택은 유지된다. 웹에서 지도 드래그, 접힘 복원, Compact→Expanded와 Expanded→Compact 손잡이 드래그를 확인했다. Expanded의 플로팅 저장 버튼은 검색창을 덮지 않는다. 축약 카드의 추천 이유는 상세/확장 목록에서 확인한다.
- `08-day1.jpg`, `09-day2.jpg`, `10-day3.jpg`: 날짜별 3개 후보를 확인했다. 검색어 `가상`, Day 3, 선택 장소는 접었다 다시 펼친 뒤 유지됐다.
- `11-place-detail.jpg`: 사진이 없는 모의 장소에서 이름·주소와 저장 버튼이 앞에 보이고 없는 추천 이유는 작은 안내로 표시된다. 뒤로 돌아가도 Day 3과 선택 장소가 유지됐다.

기존 전체 지도는 모든 마커를 화면에 맞춰 확대·축소하지 않으며 이번 UI 범위에서 변경하지 않았다. Android/iOS 실기기 터치, 키보드 회피, Safe Area 및 스크린리더는 별도 검증이 필요하다. Web/Android export는 실행 가능 번들 확인이며 실기기 검증이 아니다.
