# Android Expo Go 시연 체크리스트

다음은 Android 실기기에서 추가로 확인할 항목입니다.

1. 프로젝트 SDK와 호환되는 Expo Go에서 npx expo start의 QR을 엽니다.
2. 직접 시작 → 닉네임 → 기록 → 별점/태그 → 저장 → DNA → 지도 흐름.
3. 지도 표시, 마커, 확대/축소/드래그.
4. 마커 탭과 가로 카드 스와이프의 선택 동기화.
5. 패널 손잡이 확장/축소와 지도·리스트 제스처 충돌 여부.
6. 필터, 저장 필터, 빈 결과, 서울/부산, 검색.
7. 위치 권한 거부/허용 및 GPS 오류/지연.
8. 상세 저장 → 목록 → 저장 취소.
9. 기록 수정/삭제 후 DNA와 추천 점수 변화.
10. 저장을 기다린 뒤 앱 종료/재실행: 닉네임/기록/저장/도시 복원.
11. 키보드, 시스템 뒤로가기, 하단 시스템 내비게이션 여백.
12. 네트워크 차단 시 이미지 대체 표시, 지도 지연 안내, 로컬 데이터 이용.

APK는 추가로 지도 API 키와 서명 SHA-1 제한을 검사합니다. Expo Go 성공이 APK 지도 키 설정을 보장하지 않습니다.
